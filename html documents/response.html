The css width, max-width and picture are used to create responsive images

Responsive images using the css width property

The css width property is set to 100%, this allows the image to be responsive to viewport size but it increase the image beyound its initial size

To counter this issue of the image increasing beyound its size, the max-width css property is set to 100%. This allow the image to retain is actual dimensions without the expansion above
